# Vanilla Tooltips 3.0.0 — Forge 1.20.1

Target: Minecraft 1.20.1 / Forge.

See the [repository README](../README.md) for features and the MIT license.

Required dependency: YetAnotherConfigLib (YACL).

## Build

Use the Java version required by Minecraft 1.20.1, then run `gradlew.bat build --no-daemon` on Windows or `./gradlew build --no-daemon` on Linux and macOS. The mod JAR is written to `build/libs/`.
