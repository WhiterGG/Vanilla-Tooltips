# Vanilla Tooltips 3.0.0 — Fabric 26.3

Target: Minecraft 26.3 / Fabric.

See the [repository README](../README.md) for features and the MIT license.

Required dependencies: Fabric API and YetAnotherConfigLib (YACL). Mod Menu is optional and adds the in-game configuration screen.

## Build

Use the Java version required by Minecraft 26.3, then run `gradlew.bat build --no-daemon` on Windows or `./gradlew build --no-daemon` on Linux and macOS. The mod JAR is written to `build/libs/`.
